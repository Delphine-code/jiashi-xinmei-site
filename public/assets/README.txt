替换或新增图片
--------------
1. 把原图放进对应子目录，文件名用「小写英文 + 连字符」。
2. 在 src/data/site-data.json 的 photos 对象里改 src / alt / caption。
3. 页面代码不用动 —— 所有图片路径都从 JSON 读取。
4. 提醒：alt 必须写清楚画面内容，caption 不要编造拍摄地点与时间。
