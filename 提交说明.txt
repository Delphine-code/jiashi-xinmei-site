伽师新梅网页参赛成果文件
========================

一、压缩包内已包含
- dist：已构建的可运行静态网站成果。
- src：网站源代码、页面、组件、数据和样式。
- public：地图数据、图片和其他静态资源。
- submission：作品介绍文档、AI 工具使用情况说明等提交材料。
- package.json、package-lock.json：项目依赖和运行配置。
- 启动网页.bat、打包静态网站.bat：本地运行与构建脚本。

二、运行方法
1. 双击“启动网页.bat”，或在本文件夹终端执行 npm install 后运行 npm run dev。
2. 预览已构建成果：执行 npm run preview。
3. 已构建文件位于 dist，可作为静态网站部署。

三、提交前必须补齐
- 作品展示视频：放入“作品展示视频_待放入”文件夹，按系统要求提供 MP4。
- 作品截图：如系统要求截图，放入“作品截图_待放入”文件夹。
- 授权与来源证明：放入“授权与来源材料”文件夹。
- 核对 AI 工具说明中的豆包版本、使用日期和实际生成内容。
- 确认大会现场图片的参赛提交、公开展示授权及署名方式。

四、注意
不要删除 dist、public、src 或 submission 文件夹中的文件。提交前建议重新解压压缩包，测试网页、文档和视频是否能正常打开。
